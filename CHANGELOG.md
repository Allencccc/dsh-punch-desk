# Changelog

All notable changes to Punch Desk are documented here. Public releases use the versions published in this repository; the private source repository may use a different internal version.

## [1.0.0] - 2026-11-25

Source: dsh-punch-desk-source@v0.1.14

First public release of Punch Desk: dual entry points (Desk and Session Pane), finding capture, combined and sequential submission, Active Groups with wrap-up, cross-session asset inheritance, finding distillation, Git attribution, the settings center, and the Turn Action inbox. Includes public CI and release workflows, release guard scripts, and demo-data previews.

## [Unreleased]

- Public repository preparation: contributor docs, security policy, and release metadata.

Source: dsh-punch-desk-source@v0.1.13

- Current public feature set: dual entry points (Desk and Session Pane), finding capture, combined and sequential submission, Active Groups with wrap-up, cross-session asset inheritance, finding distillation, Git attribution, the settings center, and the Turn Action inbox.
